# Floatodo

Floatodo 是一个面向 Windows 桌面的本地优先任务计时与专注陪伴应用。

它把悬浮计时、待办任务、任务碎碎念、完成回顾、历史统计、AI 今日复盘、隐私模式、本地 Agent 接口，以及一个会陪你工作的柯基桌宠整合在同一个桌面应用中。

Floatodo 的目标不是成为一个复杂的项目管理系统，而是帮助用户更轻松地开始任务、记录过程、维持专注，并在一天结束后留下可以回顾的时间痕迹。

## 当前版本

当前版本：**v2.0**

Floatodo 2.0 已经从早期的“悬浮任务计时器”扩展为一个更完整的本地桌面工作台。

它现在不仅支持任务计时和历史记录，还支持 compact 小窗内的任务切换、沉浸式计时、任务过程记录、AI 今日复盘反馈、本地 Agent 状态读取与写入，以及更完整的柯基桌宠陪伴系统。

## 核心特性

### 桌面悬浮计时

- Windows 桌面悬浮计时窗口
- Compact 小窗模式
- 完整展开工作台
- 支持窗口拖动与置顶
- 支持 tucked 收边状态
- 支持在小窗中快速查看当前任务状态

### 任务管理

- 创建待办任务
- 设置任务名称、任务类型与预估耗时
- 启动、暂停、继续、完成任务
- 同一时间只允许一个任务进行中，避免任务状态混乱
- 支持固定任务，例如休息 5 分钟
- 支持自定义固定任务
- 支持自定义任务类型
- 支持修改任务名称、用时、备注、类型等信息

### 沉浸计时与多功能小窗

Floatodo 2.0 重新设计了 compact 小窗的使用逻辑。

Compact 模式不再只是一个简单的计时页面，而是拆分为两类状态：

- 沉浸计时页：专注展示当前正在进行的任务和计时状态
- 多功能页面：在小窗内查看任务列表、选择任务、启动任务和切换任务

这样即使已经有任务正在进行，也可以在不展开主窗口的情况下处理其他任务。

### 任务碎碎念

Floatodo 支持在任务进行中随手记录想法。

很多任务不是线性完成的。你可能会中途产生想法、记录问题、临时调整方向，或者只是想留下几句过程记录。Floatodo 将这些内容作为任务的一部分保存下来，而不是只保留最终的完成结果。

支持能力包括：

- 任务进行中多次记录碎碎念
- 类似聊天气泡的过程记录展示
- 任务详情中查看完整碎碎念
- 完成任务后填写完成备注
- Today 与 History 页面共用任务详情弹窗

### 今日回顾与历史记录

Floatodo 会将每日任务沉淀为可回顾的工作记录。

当前支持：

- 今日任务时间线
- 今日工作回顾
- 分类时间统计
- 历史任务记录
- 历史任务详情查看
- 日历热力图
- 按日期回顾过去的任务与时间分布

### AI 今日复盘

Floatodo 支持使用 DeepSeek 生成今日复盘。

用户可以在应用中配置 DeepSeek API Key 和模型名。Floatodo 会根据当天任务、用时、完成情况和任务碎碎念生成一份今日总结。

当前支持：

- 本地配置 DeepSeek API Key
- 自定义模型名，默认 `deepseek-chat`
- 根据今日任务记录生成 AI 复盘
- 对 AI 复盘进行喜欢或不喜欢反馈
- 负反馈可填写原因
- 后续复盘会参考近期反馈进行优化
- API Key 仅保存在本地数据文件中

### 隐私模式

Floatodo 是一个会长时间悬浮在桌面上的工具，因此隐私保护很重要。

当前支持：

- 在 compact 计时窗口隐藏当前任务名称
- 隐藏后显示简化文案
- tucked 收边状态同步隐藏任务信息
- 切换任务时保持隐私模式
- 适合屏幕共享、录屏或他人旁观场景

### 柯基桌宠系统

Floatodo 内置了一个柯基伙伴系统。

用户完成任务后，可以获得不同类型的陪伴反馈和奖励，例如：

- 狗粮
- 冻干
- 零食
- 玩具
- 散步
- 护理
- 技能训练

桌宠能力包括：

- 独立桌面小狗悬浮窗
- 小狗窗口可拖动
- 小狗窗口可置顶
- 小狗动画使用透明 PNG 帧
- 当前包含睡觉、玩球、吃饭等状态

柯基桌宠的定位不是单纯装饰，而是让完成任务这件事获得一点轻量、即时、可爱的反馈。

### 本地 Agent 接口

Floatodo 2.0 开始提供本地 Agent 接口，方便其他本地 AI 助手读取当前任务状态，或在用户明确要求时向当前任务写入碎碎念。

当前接口：

```txt
GET  http://127.0.0.1:39876/api/status
POST http://127.0.0.1:39876/api/actions/add-musing
```

典型用途：

- 本地 AI 助手读取当前是否有正在进行的任务
- 根据 Floatodo 当前状态，为用户提供更贴近上下文的回复
- 用户明确要求时，将一句话记录到当前任务的碎碎念中
- 与本地 WeChat Agent、桌面助手或其他自动化工具集成

设计原则：

- 仅监听本机地址 `127.0.0.1`
- 不提供公网服务
- 写入接口只在明确动作下触发
- 返回内容尽量避免暴露不必要的任务标题
- Floatodo 不可用时，外部 Agent 应该优雅降级
- 接口用于本地自动化，不用于远程同步或云端服务

## 数据保存

Floatodo 是本地优先应用。

以下数据都会保存在本机 Electron 应用数据目录中：

- 任务记录
- 任务类型
- 固定任务
- 今日记录
- 历史记录
- 小狗资料
- 应用设置
- DeepSeek API Key
- AI 今日复盘结果
- AI 复盘反馈

应用内可以通过“打开本地数据目录”查看数据文件。

这些数据不应该提交到 GitHub。

## DeepSeek 配置

Floatodo 支持通过 DeepSeek 生成今日复盘。

需要在应用内配置：

- DeepSeek API Key
- 模型名，默认 `deepseek-chat`

注意：

- API Key 只保存在本机
- 不会上传到 Floatodo 仓库
- 不应将包含 API Key 的本地数据文件提交到 GitHub
- 如果没有配置 API Key，Floatodo 的基础计时、任务管理、历史记录和桌宠功能仍然可以正常使用

## 本地 Agent API

### 获取当前状态

```txt
GET http://127.0.0.1:39876/api/status
```

用于获取 Floatodo 当前状态，例如是否有正在进行的任务、当前计时状态等。

示例：

```bash
curl http://127.0.0.1:39876/api/status
```

### 向当前任务添加碎碎念

```txt
POST http://127.0.0.1:39876/api/actions/add-musing
```

用于在用户明确要求时，将一段内容追加到当前正在进行任务的碎碎念中。

示例：

```bash
curl -X POST http://127.0.0.1:39876/api/actions/add-musing \
  -H "Content-Type: application/json" \
  -d "{\"content\":\"这里是一条任务过程记录\"}"
```

如果当前没有正在进行的任务，接口会返回相应错误状态，而不会创建新的任务。

## 设计理念

Floatodo 关注的是“真实的任务过程”，而不仅是“任务是否完成”。

很多任务并不是从开始到结束一气呵成的。它们可能会被打断、暂停、重启、修改、延迟，也可能在过程中产生很多零散想法。

Floatodo 希望帮助用户保留这些过程：

- 今天做了什么
- 每件事花了多久
- 哪些任务被中断过
- 中途产生了什么想法
- 最后完成得怎么样
- 一天结束时可以如何总结

它更像是一个贴在桌面上的轻量工作伙伴，而不是一个要求用户严格维护的项目管理系统。
